# Общая библиотека BioLab — настройка

Этот Worker добавляет общее облачное хранилище книг. Он **отдельный** от существующего Gemini Worker и не меняет его.

## Что будет доступно

- Всем, у кого есть ссылка на BioLab: просмотр списка и скачивание/открытие опубликованных книг.
- Только администратору с секретным токеном: загрузка и удаление.
- Форматы: PDF и TXT; максимум 45 МБ на файл; классы 5–11.

## Настройка Cloudflare (нужна один раз)

1. Открой Cloudflare Dashboard → **Workers & Pages** → **Create** → **Worker**. Назови, например, `biolab-shared-library`.
2. В редакторе Worker замени демонстрационный код содержимым файла `shared-library-worker.js` из этого репозитория и нажми **Deploy**.
3. В разделе **Bindings** добавь R2 bucket binding:
   - Variable name: `BOOKS`
   - Bucket: создай новый bucket, например `biolab-shared-books`.
4. В **Settings → Variables and Secrets** добавь secret:
   - Name: `LIBRARY_ADMIN_TOKEN`
   - Value: создай длинный случайный пароль. Не публикуй его в GitHub и не отправляй в чат.
5. Скопируй URL нового Worker (он будет отдельным от Gemini Worker).

## Важно

- Пока Worker не создан и R2 binding/secret не настроены, облачная библиотека не заработает. Сам GitHub Pages не может безопасно принимать и сохранять загруженные файлы.
- Текущие книги в разделе «Мои учебники» останутся локальными в твоём браузере. После запуска общей библиотеки нужные книги надо будет загрузить в неё отдельно.
- Публичный доступ означает, что любой человек со ссылкой сможет открыть файлы. Загружай только материалы, которыми разрешено делиться.
- Секрет администратора хранится в настройках Cloudflare, а не в исходном коде сайта.
